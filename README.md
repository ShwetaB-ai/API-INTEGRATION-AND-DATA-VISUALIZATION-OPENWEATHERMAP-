# API-INTEGRATION-AND-DATA-VISUALIZATION-OPENWEATHERMAP-
This project fetches real-time weather data from a public API and visualizes it using Python. It demonstrates API integration and data visualization techniques.

### 🚀 Features
- Fetches live weather data using API
- Extracts temperature, humidity, and pressure
- Visualizes data using graphs (bar and line charts)
- Supports multiple cities comparison

### 🛠 Technologies Used
- Python
- Requests (API handling)
- Matplotlib

### 🎯 Outcome
Successfully integrated a public API and created meaningful visualizations, enhancing understanding of real-time data processing and graphical representation.
